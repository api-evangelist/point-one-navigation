# Point One Navigation

> Point One Navigation operates Polaris, a GNSS RTK corrections network delivering 1-3 cm (True RTK)
> and sub-10 cm (Virtual RTK) positioning across North America, Europe, the UK, Australia, New
> Zealand, Japan and South Korea, plus FusionEngine (GNSS/INS sensor fusion) and the Atlas and
> Standard Dev Kit hardware platforms. Three developer surfaces: an NTRIP caster streaming RTCM v3.2
> MSM4, a native binary Polaris protocol, and a GraphQL platform API for device, license and
> reference-station management.

This file was generated by API Evangelist from publicly reachable material. Point One Navigation does
not publish an llms.txt of its own (https://pointonenav.com/llms.txt -> 404,
https://docs.pointonenav.com/llms.txt -> SPA shell, not a document).

## APIs

- [Polaris RTK Network (NTRIP)](https://support.pointonenav.com/polaris-ntrip-api-docs): NTRIP 1.0/2.0 caster at truertk.pointonenav.com:2102 (NA) and truertk-eu.pointonenav.com:2102 (EU). Mountpoints ITRF2014 and LOCAL. HTTP Basic auth with a per-connection unique username. Position supplied as NMEA GGA.
- [Polaris Native API (Point One Open)](https://support.pointonenav.com/native-api-docs): API key exchanged at POST https://api.pointonenav.com/api/v1/auth/token for a bearer token (604800s), then a TLS stream on rtk.pointonenav.com:8090 carrying 0xB5 0x62-framed system messages and raw RTCM3.
- [Point One Platform GraphQL API](https://docs.pointonenav.com/docs/graphql-api/quickstart): single endpoint https://graphql.pointonenav.com/graphql. Personal Access Token auth. Devices, tags, licenses, device profiles, reference stations, positions, and real-time subscriptions.

## Known gaps (probed 2026-08-05)

- No OpenAPI or Swagger document on any host.
- No AsyncAPI document and no webhook surface; real-time is GraphQL subscriptions only.
- No MCP server and no A2A agent card.
- No /.well-known/ document of any kind, including security.txt.
- No public Postman collection, no trust center, no published vulnerability-disclosure policy.
- docs.pointonenav.com does not render: the Docusaurus SPA's per-route JS chunks are not deployed, so every reference page serves the index shell.
